T·Grid — Praat TextGrid 编辑器与语音标注出图工具

T·Grid 是一款面向语言学、语音学与方言调查研究的免费开源 Praat TextGrid / Collection 可视化标注编辑器，基于 Rust（WebAssembly / Tauri）与 React 构建。所有音频解码、声学计算与标注读写均在用户设备本地完成，不向任何服务器上传数据。

完整兼容 Praat 格式

支持标准长文本、短文本、二进制及 Chronological 格式的 TextGrid、单层文件与包含音频的 Collection 集合文件。

声学可视化与微距精调

内置波形、宽带语谱图、基频（F0）与共振峰（F1–F3）轨迹显示，配备 ±40 ms 声学微距放大镜与过零点吸附。

国际音标（IPA）输入

内置云龙国际音标输入方案、Praat 三字符编码互转以及交互式虚拟 IPA 键盘，减少高频切输入法的负担。

学术论文级矢量出图

支持双标尺自动折行排版、纯矢量等值轮廓 SVG、图文分离 ZIP 包、高清 PNG、声纹海报与中英双语图例导出。

快速开始

  • 直接访问 T·Grid 在线编辑器，页面内置普通话示例与双人对话带音频示例，打开即可体验。
  • 将本地 .TextGrid、.Collection 或 .wav / .mp3 / .flac 录音文件直接拖入窗口即可加载。
  • Windows 与 macOS 用户可前往 GitHub Releases 下载原生桌面端，支持关联文件双击打开与同名音频自动配对。

常用编辑与导航能力

  • 区间与边界操作：支持拖拽微调、跨层磁吸对齐、共享边界联动、等分切分、左右合并以及全局查找替换。
  • 语境试听与回放：支持区间循环播放、标点 ±250 ms 语境播放、倍速调节与硬件音频时钟同步光标。
  • 质量检查（QA Diagnostics）：自动检测空标注区间、异常极短片段、边界重叠或越界等常见问题。
  • 离线单文件版：除在线版与桌面版外，还提供可离线直接双击运行的单文件 HTML 版本（下载 tgrid-standalone.html）。
