02 / QUICK START

基本流程

无需配置，打开即用；内置普通话与双人对话带音频示例。

STEP 01

载入标注与音频

拖入 .TextGrid、.Collection 或 .wav / .mp3 / .flac 文件。长句自动多行折行，免去长距离横向拖动；桌面端自动配对同目录同名录音。

STEP 02

切音精校与录字

按 Space 播放并按 B 落界；校对对齐结果时按 N 跳至下一空白格，拖界弹出微距窗或以方向键 ±1 ms 精调。审阅时按 E 切换只读模式。

STEP 03

回写 Praat 或导出插图

按 Ctrl+S 保存标准 Praat 格式，直接衔接后续声学提取脚本；或在导出面板选定期刊版幅与配色，输出矢量 SVG、图文分离 ZIP 或高倍 PNG。
