01 / CORE WORKBENCH

四项日常最顺手的核心能力

每个模块都可以直接点按或拖动下方小演示，直观感受软件里的真实交互。

01 / ACOUSTIC ALIGN

看谱听辨与 ±40 ms 声学微距切音

载入录音后自动绘制波形、宽带语谱图、基频（F₀）与共振峰（F₁–F₃）。拖动任意边界时会随行弹出 ±40 ms 波形放大镜；按住 Z 自动吸附波形过零点，避免切音爆音，也能用键盘以 ±10 ms 或 ±1 ms 精调。

02 / IPA & TRIGRAPH

国际音标双方案输入与整篇互转

支持「云龙国际音标（含五度声调）」和「Praat 反斜杠编码」两种输入方式，无需反复切换系统输入法，并内置点选式虚拟音标键盘。拿到旧语料里的 \sh、\ng 编码，也能整篇一键转换成标准 Unicode 音标或反向编码。

02 / QUICK START

三步上手，打开就能开始标

不需要注册账号，也不用配置任何依赖环境；如果手边暂时没有文件，页面里已经自带普通话和双人对话带音频示例。

STEP 01

拖入标注与录音文件

直接把本地的 .TextGrid、.Collection 或 .wav / .mp3 / .flac 录音拖进窗口。桌面端打开标注文件时，还会自动配对同目录下的同名录音，省去重复选择。

STEP 02

边听边打点、精细调界

按 Space 播放，听辨同时按 B 直接在播放头落边界；双击区间或按 Enter 原地输入文字与音标，按 Tab 顺次跳到下一格。需要细调边界时拖动即可唤出声学放大镜。

STEP 03

保存回 Praat 或直接出图

按 Ctrl + S 保存标准 Praat 文件，随时回到 Praat 继续跑脚本；或打开导出窗口，挑好期刊版幅与配色，一键生成高清 PNG、可二次编辑的矢量 SVG 或声纹海报。
