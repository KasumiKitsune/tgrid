T·Grid — Praat TextGrid 编辑器与语音标注出图工具

T·Grid 是一款面向语言学与语音学研究的免费开源 Praat TextGrid / Collection 标注编辑器，所有音频与标注文件均在浏览器本地解析处理，不上传至服务器。

  • 完整读写 Praat 标准文本、短文本、二进制 TextGrid 与 Collection 集合文件
  • 内置波形、宽带语谱图、基频（F0）与共振峰（F1–F3）轨迹可视化及 ±40 ms 声学微距放大镜
  • 支持云龙国际音标与 Praat 三字符输入方案及交互式虚拟音标键盘
  • 提供面向学术论文的纯矢量等值轮廓 SVG、图文分离 ZIP 包、高清 PNG、声纹海报与中英双语图例导出
