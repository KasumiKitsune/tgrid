================================================================================
T·Grid 字表语料工作区（Phase 1）图标清单与现有参考 SVG 源码
================================================================================

说明：
本文档用于汇总 T·Grid Phase 1（文件夹词表批量标注工作区）所需的全部图标：
- 第一部分：明确区分「@tgrid/icons 已有可直接复用图标」与「需新增的专用图标清单」，
  每个新增图标均注明建议文件名、组件名、中文用途、出现位置、视觉语义与建议尺寸。
- 第二部分：总结 T·Grid 现有图标库的绘制与动效规范，并原样附带 12 个最具代表性的
  现有 SVG 源码（均来自 packages/tgrid-icons/svg/），可直接提供给其他 AI 或设计师
  生成风格完全一致的新 SVG。

正式接入方式：
新绘制的 SVG 文件放入 packages/tgrid-icons/svg/<name>.svg 后，运行
packages/tgrid-icons/scripts/build-icons.mjs 即可自动编译为 @tgrid/icons，
并在 apps/web/src/corpus/corpusIcons.tsx 中一键切换为 <TGridIcon name="..." />。

================================================================================
第二部分：T·Grid 图标绘制规范与现有参考 SVG 源码
================================================================================

--------------------------------------------------------------------------------
2A. T·Grid @tgrid/icons 绘制规范总结（供设计师 / AI 绘图直接遵循）
--------------------------------------------------------------------------------

1. 画布与安全区
   - 统一属性：xmlns="http://www.w3.org/2000/svg" viewBox="0 0 16 16"
     width="16" height="16" fill="none"
   - 视觉安全区：图形主体严格落在 [2, 14] x [2, 14] 范围内（四周留约 2px 呼吸边），
     允许悬停动效轻微溢出（overflow: visible）。

2. 线条与几何气质
   - 线性描边为主，不使用厚重实心色块；仅在悬停态或状态徽章处叠加 8% ~ 16% 透明度
     的浅色底纹填充，保持克制、精密、学术工具感。
   - 笔触粗细：主轮廓 stroke-width: 1.4 ~ 1.5；次要装饰线 1.35；小箭头或强调笔画
     1.55 ~ 1.6。
   - 端点与拐角：统一 stroke-linecap: round; stroke-linejoin: round;
     矩形外框微倒圆角 rx="1" ~ "1.5"（注意：外层 UI 按钮是直角，但 16px SVG 内部
     图标路径采用克制的微圆角端点与转折，避免锯齿生硬）。

3. 语义配色与自动 Token 化规则（packages/tgrid-icons/scripts/build-icons.mjs）
   T·Grid 的图标编译器会自动把 SVG 内联 <style> 中的标准色值转换为 CSS 变量，
   从而无缝适配按钮默认态、深底反色态（button.active / button.primary）和主题色。
   请严格使用以下标准色值之一，或使用 currentColor：
   - 主描边：#374151  -> var(--tgi-stroke, #374151)
   - 次描边：#4b5563  -> var(--tgi-stroke-muted, #4b5563)
   - 弱描边：#6b7280  -> var(--tgi-stroke-subtle, #6b7280)
   - 极弱线：#9ca3af  -> var(--tgi-stroke-faint, #9ca3af)
   - 悬停深：#111827  -> var(--tgi-stroke-hover, #111827)
   - 强调蓝：#2563eb  -> var(--tgi-accent, #2563eb)
   - 蓝底纹：rgba(37, 99, 235, 0) -> 悬停 rgba(37, 99, 235, 0.08 ~ 0.14)
   - 成功绿：#16a34a / 悬停 #15803d / 底纹 rgba(22, 163, 74, 0.08 ~ 0.16)
   - 警示琥珀：#d97706 / 悬停 #b45309 / 底纹 rgba(245, 158, 11, 0.08 ~ 0.16)
   - 危险红：#dc2626 / 按压 #b91c1c

4. 微动效约定
   - 支持在内联 <style> 中编写 svg:hover 交互微动效，缓动函数统一为
     cubic-bezier(0.22, 1, 0.36, 1)（时长 0.2s ~ 0.28s）。
   - 位移克制在 0.55px ~ 1.2px，不剧烈跳动；无需写循环播放动画。
   - 严禁嵌入 <text> 依赖系统字体、严禁嵌入位图、严禁出现任何 emoji。
