## 一、设计动机与学术边界

### 1.1 为什么需要一个小于 250 KB 的跨语种声学边界模型

T·Grid 面向语言学田野调查、实验语音学研究与课堂教学，同时以 **Windows/macOS 桌面端（Tauri）**、**标准 Web（WebAssembly）** 与 **单文件 HTML** 三端同源发布。在这一运行约束下，传统语音强制对齐方案面临三项核心障碍：

1. **词典与 G2P 依赖**：常规强制对齐器（如 MFA、WhisperX）高度依赖特定语种的发音词典或大规模 ASR 声学模型，遇到无词典的汉语方言、少数民族语言或濒危田野语料时极易失灵。
2. **运行时体积与部署约束**：引入 `onnxruntime-web` 或通用推理图框架会带来 `2.5–6 MB` 运行时膨胀，直接击穿单文件 HTML（约 `3.3 MB`）的体积预算；而依赖云端 API 又难以适配田野调查对语料隐私的要求。
3. **纯规则声学切分与能量 VAD 的物理瓶颈**：在元音-鼻音韵尾（`/i-ŋ/`、`/a-n/`）、流音/滑音连读（`V-l-V`、`V-w-V`）、粤/闽/客入声唯闭塞音韵尾（`[-p̚, -t̚, -k̚, -ʔ]`）及送气塞音 VOT 分界上，传统能量与谱过渡启发式算法易产生 25–60 ms 漂移；田野录音中常见的 50/60 Hz 交流电底噪、翻纸声与句首吸气声也经常击穿纯能量/过零率 VAD。

**`TGrid-AcouSeg 1.0`** 采用「**物理可解释信号处理保底 + 204 KB 共享骨干声学网络提纯局部后验 + 受限半马尔可夫动态规划（DP）全局拓扑约束**」的混合架构：

- **语言无关、零词典依赖**：网络仅识别人类声道共有的 8 类物理发音方式、5 ms 音素边界、10 ms 音节边界与语音活动概率，天然适用于未见方言与跨语种标注。
- **纯 Rust 零外部依赖推理**：整套前向推理器不足 250 行安全 Rust 代码，不依赖任何第三方神经网络库，直接编译至原生二进制与 `wasm32-unknown-unknown` 执行。
- **可确定的安全回退**：所有切分均受现有半马尔可夫 Viterbi DP 约束，段数严格守恒、边界严格单调；面对低信噪比或纯噪声区间自动触发置信度阻尼与等分回退。

### 1.2 明确的学术使用边界

为捍卫实验语音学研究的物理可解释性与论文可复现性，T·Grid 对神经网络的引入划定了严格红线：

| 功能模块 | 是否引入 `TGrid-AcouSeg 1.0` | 设计依据 |
| :--- | :--- | :--- |
| **智能声学切分**（按音节/词、按声韵/音素） | **混合引入**（局部后验 + 原生 5 ms 短窗 DSP + Viterbi DP） | 辅助边界定位与候选打分，最终切点仍可人工微调核校，且保留确定性 DP 拓扑约束与低置信度回退 |
| **声学边界吸附** | **引入**（复用同一骨干的 5 ms 边界概率） | 支持一键声学边界吸附；拖拽边界自动吸附默认关闭，可在偏好设置中按需开启 |
| **词表自动切词 / 抗噪 VAD** | **共享骨干引入**（复用 `vad_speech` 与 `SIL/STOP_CL` 通道） | 额外权重开销为 0 字节；显式区分词内塞音闭塞与真静音/翻纸/工频底噪 |
| **基频（`F0`）提取** | **严禁引入**（保持经典 NSDF/MPM 物理算法） | 声调与语调研究要求 F0 具有严格物理定义（对标 Praat），避免神经回归平滑幻觉与训练语种调域偏置 |
| **共振峰（`F1–F3`）测量** | **严禁引入**（保持经典抗混叠降采样 + LPC 全极点分析） | 元音声学图依赖源-滤波器声道极点物理定义，不可被黑盒网络声道长度偏置污染 |
| **符号级文本拆分**（汉字/拼音/IPA 状态机） | **严禁引入**（保持 100% 确定性规则） | 避免普通话统计 G2P 误判汉语方言同字异音 |

## 二、声学前端与零漂移特征规范

跨语言部署微型模型最常见的隐性失效来源，是训练端（Python `librosa`/`torchaudio`）与推理端（Rust/WASM）在重采样相位、窗函数分母或 Mel 滤波器定义上的细微偏差。`TGrid-AcouSeg 1.0` 制定了自包含的单精度确定性声学前端规范，Rust 实现（`crates/tg-core/src/nn/features.rs`）与 Python 参考实现（`tools/microseg-train/model/features_ref.py`）逐公式镜像对齐，并支持通过 Rust CLI `tools/microseg-train/feat-dump-cli` 直接导出训练特征。

### 2.1 规范化 16 kHz 重采样

- 对任意输入采样率 $F_{s,\text{in}}$ 的单声道 `f32` 波形，首先过滤非有限值并扣除全局直流偏置 `dc_mean`。
- 若 $F_{s,\text{in}} = 16000\text{ Hz}$，直接进入分帧；否则使用固定查表驱动的 **Hann-Sinc 带限重采样器**（截止频率 $f_c = \min(7600\text{ Hz}, 0.45 F_{s,\text{in}})$，单侧零交叉数 $N_z = 16$，每零交叉 512 阶相位查找表线性插值），输出 $F_s = 16000\text{ Hz}$ 网格点采样值。

### 2.2 双时间尺度分帧（10 ms 主帧 + 5 ms 亚帧瞬态）

- **主分析帧**：帧移 `hop = 160 samples`（`10 ms`，帧率 100 Hz），窗长 `win = 400 samples`（`25 ms` 周期型 Hann 窗 $w[n] = 0.5 - 0.5\cos(2\pi n / 400)$），零填充至 `n_fft = 512`，以双实数帧打包单次 512 点基 2 FFT 计算功率谱。
- **亚帧瞬态内嵌**：清不送气塞音 VOT 常仅 `8–18 ms`，闪音 `[ɾ]` 仅 `15–25 ms`。每 `10 ms` 主帧内额外提取左半帧 `[0, 5 ms)` 与右半帧 `[5, 10 ms)`（各 `80 samples`）的时域全频带能量与一阶高通差分能量，并由输出头并行预测两个 `5 ms` 子槽的音素边界概率。这使得骨干网络在维持 100 Hz 极低计算量与 `670 ms` 宽感受野的同时，原生获得 **200 Hz（`5 ms`）** 的音素边界时间分辨率。

### 2.3 32 维输入特征定义（`D_in = 32`）

| 通道索引 | 维度 | 物理含义与计算定义 |
| :--- | :---: | :--- |
| `ch[0..24]` | 24 | 频域预加重（$\alpha = 0.97$，$G[k] = 1 + 0.97^2 - 2 \cdot 0.97\cos(2\pi k / 512)$）后的 24 带 HTK-Mel 对数功率谱（`60 Hz – 7600 Hz`，保护项 `+ 1e-10`） |
| `ch[24..26]` | 2 | 左右两个 `5 ms` 半帧的短时全频带对数均方能量 `sub_e0`, `sub_e1` |
| `ch[26..28]` | 2 | 左右两个 `5 ms` 半帧的一阶高通差分（$d[n] = x[n] - x[n-1]$）对数能量 `sub_hf0`, `sub_hf1`，用于精准捕获塞音除阻爆破脉冲 |
| `ch[28]` | 1 | 半波整流正谱通量 $\text{clamp}(\|\max(0, \tilde{M}_t - \tilde{M}_{t-1})\|_2 / 2.5, 0, 1)$ |
| `ch[29]` | 1 | 归一化高频谱倾斜度 $\text{clamp}(\text{mean}(\tilde{M}_{t, 16..24}) - \text{mean}(\tilde{M}_{t, 0..6}), -1, 1)$ |
| `ch[30]` | 1 | `25 ms` 窗内时域过零率 $\text{clamp}(\text{ZCR}_t / 0.5, 0, 1)$ |
| `ch[31]` | 1 | 4 kHz 抽取自相关短时清浊度 $V_t \in [0, 1]$（滞后范围 `75–450 Hz`，低能量门限自动归零） |

### 2.4 有界峰值锚定归一化（拒绝 Z-score CMVN）

本前端**严禁使用整段零均值单位方差标准化（Z-score CMVN）**：在纯底噪或极低信噪比切片中，除以极小标准差会将 `-65 dBFS` 静音噪声放大成高能量伪语音；且在 `0.25 s` 短音节切片与 `120 s` 连续词表录音之间，全局均值方差会发生剧烈漂移。

对 `ch[0..28]` 全部 28 个分贝能量通道，统一执行**有界峰值锚定相对分贝归一化**：

- 对长度 $\le 12\text{ s}$（$\le 1200$ 帧）的切片，参考能量取 $E_{\text{ref}} = \max(\text{P95}(E_{\text{tot}}), -45.0\text{ dBFS})$；
- 对 $> 12\text{ s}$ 的长录音（VAD 模式），以步长 20 帧计算对称 `8 s` 滑动窗口 $[t - 4\text{s}, t + 4\text{s}]$ 的局部 $\max(\text{P95}, -45.0\text{ dBFS})$ 并线性插值；
- 归一化映射：

$$\tilde{E} = \frac{\text{clamp}(E - E_{\text{ref}}, -55.0, +5.0) + 25.0}{30.0} \in [-1.0, +1.0]$$

当正常人声电平在 `-2 dBFS` 至 `-28 dBFS` 间变动时，峰值始终锚定在 `+0.83` 附近；当整段为 `-65 dBFS` 纯底噪时，因 `-45.0 dBFS` 下限保护，所有能量通道稳定落在 `[-1.0, -0.67]` 静默区，杜绝噪声放大幻觉。

## 三、模型架构与 `.tgnn` 二进制权重格式

### 3.1 18 层多尺度空洞 ConvNeXt-1D 骨干

`TGrid-AcouSeg 1.0` 采用非因果多尺度空洞深度可分离一维卷积网络（Dilated Depthwise-Separable ConvNeXt-1D），共 **18 个卷积层**（1 个 Stem 层 + 5 个空洞残差块 + 1 个局部聚焦深度卷积颈部层 + 1 个线性多任务输出头）。

- **为何不选用 BiGRU/BiLSTM**：T·Grid 切分与自动 VAD 均为非流式区间批处理，对称卷积拥有严格有界的平移不变感受野（`670 ms`，当前帧左右各 `±330 ms`），在 `0.25 s` 短音节切片与 `180 s` 长录音间无循环隐藏状态漂移，且无门控非线性查表误差。
- **边缘复制填充（Replicate Padding）**：所有深度卷积统一使用边缘帧复制填充，避免短切片首尾因补零产生虚假的“静音→语音”边界峰。
- **算子极简化**：推理图仅包含 Pointwise Conv1d、Depthwise Conv1d、残差相加与 `ReLU6`；训练期全部 `BatchNorm1d` 在导出前严格解析折叠进对应卷积权重与偏置。

### 3.2 12 维多任务输出头

每 `10 ms` 帧输出 12 个 `f32` logit，经解码得到四组互补的声学后验：

1. **`out[0..8]`：8 类语言无关发音方式（经 Softmax）**：
   - `0: SIL` — 纯静音、环境底噪、呼吸声、翻纸声、麦克风低频喷麦冲击；
   - `1: STOP_CL` — 塞音/塞擦音成阻闭塞持阻期、喉塞音 `[ʔ]` 及粤/闽/客/越入声唯闭塞音韵尾 `[-p̚, -t̚, -k̚, -ʔ]`；
   - `2: BURST_ASP` — 塞音/塞擦音除阻爆破脉冲与送气段（VOT）；
   - `3: FRIC_VL` — 清擦音与咝音（`[f, s, ʂ, ɕ, ʃ, x, h, ɬ, θ, ç]`）；
   - `4: OBS_VD` — 真浊塞音、浊擦音、浊塞擦音（`[b, d, g, v, z, ʒ, ʐ, ʑ, ɦ, dz]`）；
   - `5: NASAL` — 鼻辅音（`[m, n, ɳ, ɲ, ŋ]`），专门解决元音-鼻音韵尾边界缓变问题；
   - `6: LIQUID_GLIDE` — 边音、近音、闪音与滑音（`[l, ɹ, ɻ, ɾ, j, w, ɥ]`）；
   - `7: VOWEL` — 单元音、复元音、鼻化元音、成音节响音（`[m̩, ŋ̍]`）及嘎裂/气声元音。
2. **`out[8..10]`：双亚帧音素边界（经 Sigmoid，展开为 200 Hz / `5 ms` 概率曲线）**：分别对应 `[10t, 10t+5 ms)` 与 `[10t+5 ms, 10t+10 ms)` 两个亚帧的音素/声韵切分概率。
3. **`out[10]`：音节/词级边界（经 Sigmoid，100 Hz / `10 ms`）**：聚焦音节成阻起点，抑制音节内部声韵交界响应，解耦音节级与音素级切分目标。
4. **`out[11]`：校准语音活动概率（经 Sigmoid，100 Hz / `10 ms`）**：保持词内塞音短闭塞（`STOP_CL`）不断裂，同时抑制翻纸、吸气与工频噪声。

### 3.3 `.tgnn` 64 字节对齐二进制协议

`.tgnn` 为小端序、零序列化依赖的紧凑二进制格式，支持 `include_bytes!` 编译期直嵌与运行时外部文件加载：

| 字节区间（以 `h=96` 为例） | 大小 (Bytes) | 字段结构与说明 |
| :--- | ---: | :--- |
| `0..64` | `64` | **文件头 `TgnnHeader`**：`0..4` Magic `b"TGNN"`；`4..6` `version=1 (u16)`；`6..8` `arch_id=1 (u16)`；`8..12` `sample_rate=16000 (u32)`；`12..14` `hop_samples=160 (u16)`；`14..16` `in_dim=32 (u16)`；`16..18` `out_dim=12 (u16)`；`18..20` `hidden_dim (u16)`；`20..22` `num_layers=18 (u16)`；`22..24` `reserved=0 (u16)`；`24..28` `weight_bytes (u32)`；`28..32` `channel_count (u32)`；`32..36` `crc32_ieee (u32)`（覆盖 `64..EOF` 全量字节的 IEEE 802.3 CRC32，多项式 `0xEDB88320`）；`36..64` `model_tag ([u8; 28])`（UTF-8/ASCII，末尾补 `0x00`）。 |
| `64..352` | `288` | **层描述表 `[LayerDesc; 18]`（每项 16 B）**：`op_kind (u8: 0=PW, 1=DW)`、`act_kind (u8: 0=Id, 1=ReLU6)`、`res_mode (u8: 0=None, 1=Push, 2=PopAdd)`、`kernel (u8)`、`dilation (u16)`、`c_in (u16)`、`c_out (u16)`、`param_idx (u16)`、`weight_off (u32)`。 |
| `352..8,848` | `8,496` | **逐通道反量化缩放因子 `scales: [f32; 2124]`**（满足 $W_{\text{fp32}}[o, i] \approx \text{scales}[o] \times W_{\text{i8}}[o, i]$）。 |
| `8,848..17,344` | `8,496` | **折叠 BN 后的偏置 `biases: [f32; 2124]`**（偏移 `17,344 = 271 × 64`，下一区精确 64 字节缓存行对齐；`h=48` 偏移 `8,896 = 139 × 64` 同样精确对齐）。 |

### 3.4 纯 Rust 零依赖推理与比特级数值对拍

Rust 推理器（`crates/tg-core/src/nn/tgnn.rs`）采用乒乓双缓冲与单残差缓存，点积在 `f64` 精度下累加后乘以逐通道 `scale` 并加 `bias` 转回 `f32`，消除跨平台 SIMD 与 Python BLAS 浮点结合律差异。在 `crates/tg-core/tests/nn_parity_test.rs` 自动化门禁测试中，对内置 `tgrid-acouseg-1.0.tgnn` 的三组多采样率黄金向量验证结果如下：

#### 关键标签工程
- **塞音闭塞/除阻自动二相拆分**：对所有未拆分闭塞期的清塞音/塞擦音区间，在 `2.5 ms` 步长高频能量包络上自动搜索正跳变 $\ge 6\text{ dB}$ 且前后对比 $\ge 8\text{ dB}$ 的除阻时刻，自动拆分为 `STOP_CL`（成阻闭塞）与 `BURST_ASP`（除阻送气）；若全段无除阻跃升（如粤/闽入声唯闭塞音韵尾），则自然保持为 `STOP_CL`。
- **高斯时间软标签**：5 ms 音素边界采用 $\sigma_p = 4.8\text{–}6.5\text{ ms}$ 高斯峰值软目标，10 ms 音节边界采用 $\sigma_s = 8.5\text{–}9.5\text{ ms}$，缓解人工标注与强制对齐的固有毫秒抖动。

### 4.2 9 项田野/耳语/孤立单字物理增强与两阶段 QAT 训练

训练数据流水线（`tools/microseg-train/dataset/augment_field.py`）集成 9 项面向真实田野调查场景的在线声学增强：
1. **句首呼吸与翻纸邻接拼接**（`p=0.35`，强制 `SIL / vad=0`）；
2. **近讲喷麦低频脉冲冲击**（`20–110 Hz`，`p=0.25`）；
3. **50/60 Hz 工频交流哼声与 2/3 次谐波**（SNR `10–26 dB`，`p=0.25`）；
4. **直达声主峰对齐房间混响卷积**（`RT60 0.15–0.65 s`，`p=0.30`，杜绝混响引起的边界后移）；
5. **元音嘎裂声（Creaky Voice）周期倍增调制**（`p=0.20`，保持 `VOWEL` 标签）；
6. **离轴高频滚降与 8 kHz 窄带退化**（`p=0.25`）；
7. **语速变速缩放**（$\alpha \in [0.78, 1.28]$，同步精确缩放边界时间戳，`p=0.30`）；
8. **弱气声/耳语正样本分支**（低频基波衰减 + 语音包络调制高频气声激励 + `-28 ~ -42 dBFS`，`p=0.18`，严格保持 `vad=1`）；
9. **孤立单音节/短爆破/清擦正样本切片**（2–4 个 `80–450 ms` 单字嵌于 `300–700 ms` 静音或轻底噪中，含 35% 耳语化，保持 `vad=1`）。

**两阶段训练协议**：
- **Stage 1（35 轮 FP32）**：多任务联合损失 $\mathcal{L} = 1.0\mathcal{L}_{\text{WCE}} + 2.5\mathcal{L}_{\text{ContFocal, pbnd}} + 2.0\mathcal{L}_{\text{ContFocal, sbnd}} + 1.0\mathcal{L}_{\text{BCE, vad}}$，`AdamW(lr=2e-3, wd=1e-4)` + Cosine 退火；
- **Stage 2（10 轮 INT8 QAT）**：解析折叠全部 `BatchNorm1d`，启用逐输出通道对称 `FakeQuantize([-127, 127])` 与 STE 直通梯度估计，以 `lr=5e-5` 校准 10 轮。实测 INT8 导出几乎零掉点（甚至因隐式正则化使综合验证集音素 F1@20ms 从 `70.70%` 升至 `70.85%`、音节 F1@20ms 从 `59.52%` 升至 `59.78%`）。

*(注：模型内部迭代先后经历了仅含英语原型验证、中英均衡+耳语增强迭代，最终扩充 5 类方言/关键音类与原生 5 ms 短窗 DSP 混合融合并定型为 `TGrid-AcouSeg 1.0`。)*

### 5.4 已知局限

本规范如实记录 `TGrid-AcouSeg 1.0` 当前存在的两项边界局限，便于研究者合理设定预期并在必要时借助方言微调解决：

1. **方言长句（5–12 秒、8–20 词）的纯无文本音节级切分**：在无任何文本音素时长先验、仅给出等权音节个数的超长方言整句中，若句中存在较长停顿或快慢语速剧烈交替，动态规划可能出现全局漂移（`dialect_real` 整句音节级 MAE 为 `109.07 ms`，略逊于直接追踪能量包络谷点的纯规则 `100.03 ms`）。建议对长录音先执行抗噪 VAD 分句或按词组粗切，再在短语/单音节尺度上执行智能声韵与音素拆分。
2. **极弱耳语场景下的 VAD 召回率偏保守**：用于构建方言训练子集的 `MMS_FA` CTC 强制对齐在词间会产生少量稀疏空隙帧（在训练标签中落入 `SIL / vad=0`），导致 `TGrid-AcouSeg 1.0` 的 `vad_speech` 通道在极低信噪比纯气声/耳语片段上精确率极高（`98.1%`）但召回率偏低（`61.3%`）。后续版本计划对强制对齐词内 `< 120 ms` 的稀疏空隙施加 `vad=1` 闭合掩码以进一步提升弱耳语召回。

## 六、复现训练与自定义方言微调指南

所有训练、导出与微调工具均位于仓库 `tools/microseg-train/` 目录，详细命令索引见 [`tools/microseg-train/README.md`](../tools/microseg-train/README.md)。

### 6.1 方案 A：使用自有方言语料本地微调（推荐，CPU 2–4 分钟）

当您在 T·Grid 中已核校 **30–200 条**（约 **3–20 分钟**）目标方言或田野语料的 `.wav + .TextGrid` 后，无需 GPU，可直接在本地 CPU 上完成微调：

1. **微调机制（防小样本过拟合）**：
   - 严格冻结底层通用声学特征提取器 `stem_pw` 与前 4 个 ConvNeXt 残差块（`L00..L12`），**仅解冻末块 `b4`、`head_neck` 与 `head_out`（`L13..L17`，约占总参数 20.3%）**；
   - **兼容非完整层级 TextGrid 的掩码蒸馏（Masked Partial-Tier + KL Anchor）**：若您的语料仅标注了汉字/音节层而未标音素层，脚本自动仅激活音节与 VAD 监督，并在未标注通道上以冻结的内置多语种基座模型作为软教师（$\lambda_{\text{kd}} = 0.25$），保证微调后不会破坏原有的声韵/音素细切能力；
   - **零格式变更导出**：直接输出同构的 `208,576 bytes` `.tgnn` 文件，无需修改 Rust/WASM 推理代码即可加载。

2. **三步执行**：

```bash
# 第一步：安装轻量依赖（仅需 PyTorch CPU 版与音频读写库）
cd tools/microseg-train
pip install numpy scipy soundfile torch

# 第二步：指向本地配对 .wav + .TextGrid 文件夹执行微调
python finetune_dialect.py \
  --input ./my_dialect_corpus \
  --output ./artifacts/my_dialect_acouseg.tgnn \
  --base-model ../../crates/tg-core/src/nn/weights/tgrid-acouseg-1.0.tgnn \
  --tag acouseg-1.0-dialect \
  --epochs 16

# 第三步（可选）：将自定义 .tgnn 替换或加载后，用黄金测试检验格式完整性
```

### 6.2 方案 B：在 Google Colab / Linux GPU 上从零复现训练

拥有免费或付费 GPU（如 Google Colab T4 / L4）时，端到端完成数据准备、35 轮 FP32 预训练与 10 轮 INT8 QAT 校准约需 **20–35 分钟**：

```bash
cd tools/microseg-train
pip install -r requirements.txt

# 1. 准备多语种与方言训练切片（如需跳过 CC-BY-NC-4.0 的 MMS_FA 方言对齐，可追加 --skip-dialects）
python dataset/prepare_corpora.py \
  --work-dir ./data/acouseg \
  --aug-copies 2 \
  --workers 8 \
  --version acouseg-1.0

# 2. 训练标准档 TGrid-AcouSeg 1.0 (h=96, 203.69 KiB) 并导出 .tgnn 与黄金对拍文件
python train_qat.py \
  --data-dir ./data/acouseg \
  --out-dir ./artifacts \
  --hidden-dim 96 \
  --version-tag acouseg-1.0 \
  --fp32-epochs 35 \
  --qat-epochs 10 \
  --export-golden
```

如需将重新训练的权重同步更新至 `crates/tg-core` 并通过全工作区回归测试：

```bash
# 同步重建黄金对拍向量
python tools/microseg-train/regen_golden.py \
  crates/tg-core/src/nn/weights/tgrid-acouseg-1.0.tgnn \
  crates/tg-core/tests/fixtures/nn_parity_golden.bin

# 运行全工作区单元测试（含 Python-Rust 数值一致性与 CRC32 校验）
cargo test --workspace
```
